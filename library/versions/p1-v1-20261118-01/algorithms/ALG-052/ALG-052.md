# ALG-052

Fixed-seed generalized assignment makes small CVRP route groups using exact capacity-state search.

The entry records the interface, reference code and exact implementation hash. This is an independent project reference using the Python 3.13 standard library. [ALG-052.json](ALG-052.json) · [seeded_assignment.py](seeded_assignment.py)
