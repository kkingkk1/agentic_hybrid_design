# ALG-044

Cycle patching converts a successor assignment into one TSP tour by swapping successors across disjoint cycles.

The entry records the interface, reference code and exact implementation hash. This is an independent project reference using the Python 3.13 standard library. [ALG-044.json](ALG-044.json) · [cycle_patching.py](cycle_patching.py)
