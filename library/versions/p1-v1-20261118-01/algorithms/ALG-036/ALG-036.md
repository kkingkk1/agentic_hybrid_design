# ALG-036

Farthest insertion chooses a vertex remote from the current symmetric TSP tour and inserts it at its cheapest position.

The entry records the interface, reference code and exact implementation hash. This is an independent project reference using the Python 3.13 standard library. [ALG-036.json](ALG-036.json) · [farthest_insertion.py](farthest_insertion.py)
