# ALG-065

Record-to-record travel accepts moves inside a fixed deviation from the best seen objective.

The entry records the interface, reference code and exact implementation hash. This is an independent project reference using the Python 3.13 standard library. [ALG-065.json](ALG-065.json) · [record_travel.py](record_travel.py)

The relevant excerpts or source files were inspected for the indicated mechanism. The Python adaptation and its operating boundaries are documented in the entry.
