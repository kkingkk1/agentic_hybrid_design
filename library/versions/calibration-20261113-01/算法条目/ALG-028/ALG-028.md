# ALG-028：Hungarian 最小费用分配

算法正文和摘要见 [ALG-028.json](ALG-028.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [hungarian.py](hungarian.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `hungarian`。输入有限费用矩阵，行数不超过列数；输出最小费用和各行对应列下标。只支持完全费用矩阵，允许负费用；不可用边、额外容量与路线约束需另行建模。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：多组矩形小矩阵与全排列枚举比较，包括负费用及非法维度。另与 SciPy 1.17.1 的线性分配求解器比较 300 个矩形矩阵；该库仅用于验证，不是参考实现依赖。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Columbia IEOR 8100 课程材料 *Lecture 6: The Hungarian Algorithm*（2012 年，作者未核实）：[来源原文](https://www.columbia.edu/~cs2035/courses/ieor8100.F12/lec6.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：Columbia 讲义中 Hungarian 的对偶势、零约化费用和匹配增广。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
