# ALG-017：A* 路径树搜索

算法正文和摘要见 [ALG-017.json](ALG-017.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [astar_tree.py](astar_tree.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `astar_tree`。输入有限显式图、起终点和启发函数；返回代价及路径，无路径返回 None。所有边权须有限非负；启发函数须返回有限非负值、可采纳且终点启发值为零。实现只校验访问到的边和调用到的启发值，无法验证全图非负性或可采纳性。无全局闭集，可能重复扩展状态。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：80 个小图与简单路径穷举比较，另检查非零可采纳启发。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Dan Klein、Pieter Abbeel 等，*CS188 Informed Search*（Berkeley，2026 年课程讲义）：[来源原文](https://inst.eecs.berkeley.edu/~cs188/sp26/assets/lectures/cs188-sp26-lec03.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：Berkeley CS188 讲义的 A*、可采纳启发和路径树搜索。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
