# ALG-027：背包 Cover 不等式分离

算法正文和摘要见 [ALG-027.json](ALG-027.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [cover_cut.py](cover_cut.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `violated_cover`。输入非负重量、容量及各分量在 0 到 1 的点，返回一个违反 cover 的物品下标集合或 None。仅分离基本 cover 不等式，不自动求解 LP 或加入求解器；None 仅表示未找到该类型违反。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：100 组小背包与全部子集比较是否存在违反的 cover；检查所发现的割对所有整数可行解有效。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Illinois IE 511 课程材料 *Lecture 28: Column Generation, Knapsack Cover Inequalities*（2025 年，作者未核实）：[来源原文](https://karthik.ise.illinois.edu/courses/ie511/lectures-sp-25/lecture-28.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：Illinois 整数规划讲义的 knapsack cover 定义与有效不等式。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
