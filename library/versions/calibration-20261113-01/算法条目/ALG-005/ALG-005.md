# ALG-005：对称 TSP 的 2-Opt 局部改进

算法正文和摘要见 [ALG-005.json](ALG-005.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [two_opt.py](two_opt.py) 是本项目独立实现的 2-Opt 组件，不是论文作者源码。使用 Python 3.13 标准库；`two_opt` 接收不重复起点的完整顶点排列和对称非负距离矩阵，每轮选择最佳严格改善移动，直到没有合法的改善移动，返回闭合回路长度和改进后的排列。

该实现不处理非对称距离、容量、时间窗或求解时限。浮点输入按其二进制值作精确有理数运算，浮点结果可能舍入或溢出。代码文件版本和入口见 JSON 的 `code` 字段；本项目参考实现尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check_two_opt.py](check_two_opt.py) 检查交叉路径、异常输入，以及 150 个随机对称小实例的全部合法邻居；另以独立有理数代价计算核对 120 个小实例。该检查不是性能基准。

**出处：** Ulrich A. Brodowsky、Stefan Hougardy, *The Approximation Ratio of the 2-Opt Heuristic for the Euclidean Traveling Salesman Problem*。[作者稿 arXiv:2010.02583v3](https://arxiv.org/html/2010.02583v3)第 1—2 节于 2026-11-07 核查；[STACS 2021 发表版 PDF](../../../../../data/P1_calibration_papers/two_opt_brodowsky_hougardy_stacs_2021.pdf)第 3—4 个 PDF 页的定义及算法于 2026-11-10 复核。两版未逐项对读。该文用于核对算子定义和欧氏问题边界，不作为其首次提出的出处；未运行论文作者源码。
