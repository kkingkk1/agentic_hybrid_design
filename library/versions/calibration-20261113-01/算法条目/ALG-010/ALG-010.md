# ALG-010：Held–Karp TSP 子集动态规划

算法正文和摘要见 [ALG-010.json](ALG-010.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [held_karp.py](held_karp.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `held_karp`。输入有限数值方阵和起点，输出最优回路代价与含首尾起点的顶点序列。完整有向矩阵必需；支持负边但不处理缺边、容量或时间窗。单顶点回路按零代价处理。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：72 个有向小实例与排列穷举比较，并核查单点和异常输入。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** David Eppstein，*Exact TSP Algorithm*（UCI，2026 年课程讲义）：[来源原文](https://ics.uci.edu/~eppstein/163/lecture5b.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：UCI 图算法讲义的 TSP 子集状态、递推和回溯；讲义列出 Bellman 及 Held–Karp 的原论文。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
