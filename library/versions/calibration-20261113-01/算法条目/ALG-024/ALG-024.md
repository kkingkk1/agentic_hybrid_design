# ALG-024：分数背包线性松弛

算法正文和摘要见 [ALG-024.json](ALG-024.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [fractional_knapsack.py](fractional_knapsack.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `fractional_knapsack`。输入正重量、非负价值及非负容量，输出精确松弛目标与每件物品的比例。仅适用于单容量、可分物品和非负价值；结果可为 0/1 背包上界，但不一定是整数可行解。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：140 组小实例与分数多面体顶点枚举比较，并核查容量。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Emory 课程材料 *Knapsack Branch and Bound*（作者和年份未核实）：[来源原文](https://www.cs.emory.edu/~cheung/Courses/253/Syllabus/BranchBound/Docs/Knapsack-branch+bound.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：讲义中分数背包松弛、价值密度与整数背包上界。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
