# ALG-009：高代价请求移除

算法正文和摘要见 [ALG-009.json](ALG-009.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [worst_removal.py](worst_removal.py) 是本项目参考论文独立实现的移除组件，使用 Python 3.13 标准库。`worst_removal(routes, node_request, count, power, objective, rng)` 返回新路线及移除请求。输入路线不包含仓库；映射必须恰好覆盖访问节点，同一请求的节点须属于同一路线。目标回调接收不可变路线快照，按论文约定计算不将移除请求计入请求银行的目标值。

每次移除后重新计算其余请求的收益。空路线保留在返回结果中，目标回调须按实际问题决定空路线是否产生车辆成本。映射无法暴露本已缺失的取送节点；请求银行、修复和最终可行性由调用方负责。该实现不等同于 [CASE-002](../../组合案例/CASE-002/CASE-002.md) 的第三方代码。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check_worst_removal.py](check_worst_removal.py) 检查逐次重算、随机排序、成组移除、输入不变和异常输入；另比较 100 组固定种子的独立移除过程。未运行完整 ALNS，也未进行性能基准。

**出处：** Stefan Røpke、David Pisinger, *An Adaptive Large Neighborhood Search Heuristic for the Pickup and Delivery Problem with Time Windows*，[2006 年发表版 MinerU 全文](../../../../../data/P1_calibration_papers/ALNS_2006_MinerU/full.md)第 3.1.3 节及算法 3；[正式发表 DOI](https://doi.org/10.1287/trsc.1050.0135)。2026-11-12 核对解析正文、本地原 PDF 第 6 页（印刷页 460）的算法 3，以及 CASE-002 所收录的第三方代码；未运行论文作者源码。
