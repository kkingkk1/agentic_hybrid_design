# ALG-008：Shaw 相关请求移除

算法正文和摘要见 [ALG-008.json](ALG-008.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [shaw_removal.py](shaw_removal.py) 是本项目参考论文独立实现的移除组件，使用 Python 3.13 标准库。`shaw_removal(routes, node_request, count, power, relatedness, rng)` 返回新路线及移除请求。路线只包含访问节点，映射必须恰好覆盖这些节点，同一请求的节点须属于同一路线；输入不被修改。`relatedness(a, b)` 的值越小表示越相关，调用方须基于移除前状态提供稳定结果。

例如，路线为 `[["ap", "ad", "bp", "bd"], ["cp", "cd"]]`，节点分别属于请求 `a`、`b`、`c`。若先选 `a`，且 `b` 比 `c` 更相关，随机下标为零时移除 `a` 和 `b`，返回 `[[], ["cp", "cd"]]` 及 `["a", "b"]`。

组件不生成论文中的距离、时间、需求与车辆兼容性相关性公式，也无法识别映射中已缺失的取送节点；调用方负责提供正确映射、请求银行和可行性检查。它不等同于 [CASE-002](../../组合案例/CASE-002/CASE-002.md) 的第三方代码。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check_shaw_removal.py](check_shaw_removal.py) 检查取送节点成组移除、排序偏向、输入不变和异常输入；另比较 100 组固定种子的独立选择过程。未运行完整 ALNS，也未进行性能基准。

**出处：** Stefan Røpke、David Pisinger, *An Adaptive Large Neighborhood Search Heuristic for the Pickup and Delivery Problem with Time Windows*，[2006 年发表版 MinerU 全文](../../../../../data/P1_calibration_papers/ALNS_2006_MinerU/full.md)第 3.1.1 节及算法 2；[正式发表 DOI](https://doi.org/10.1287/trsc.1050.0135)。2026-11-12 核对解析正文、CASE-002 所收录的第三方代码，并因 MinerU 的算法 2 排版缺失，查验本地原 PDF 第 6 页（印刷页 460）的算法 2。未运行论文作者源码。
