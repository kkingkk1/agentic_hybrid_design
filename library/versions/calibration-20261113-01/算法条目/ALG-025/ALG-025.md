# ALG-025：背包拉格朗日松弛上界

算法正文和摘要见 [ALG-025.json](ALG-025.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [lagrangian_knapsack.py](lagrangian_knapsack.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `lagrangian_knapsack`。输入非负重量、价值、容量和固定乘子，输出上界与松弛子问题的所选物品。只计算给定乘子的上界，不优化乘子；松弛选择可能超容量，不能直接视为可行解。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：180 组小背包与全部可行子集比较，检查上界不低于最优值。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** CMU 课程材料 *Lagrangian Relaxation*（作者和年份未核实）：[来源原文](https://mat.tepper.cmu.edu/classes/mstc/relax/node9.html)。2026-11-12 通过 Exa 阅读相关正文节选：CMU Lagrangian Relaxation 讲义中的最大化背包上界及乘子。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
