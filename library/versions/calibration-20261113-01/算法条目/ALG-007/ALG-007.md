# ALG-007：模拟退火接受准则

算法正文和摘要见 [ALG-007.json](ALG-007.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [annealing_acceptance.py](annealing_acceptance.py) 是本项目独立实现的接受与降温组件，使用 Python 3.13 标准库。`annealing_accept(current, candidate, temperature, rng)` 判断候选；仅在候选较差时抽取随机数。`cool_temperature(temperature, rate)` 做一次几何降温，结果下溢为零时抛出异常，由调用方决定停止或其他处理。

该组件不设置初始温度、最低温度或停止条件，不计算目标、不生成候选，也不检查可行性。接受判断采用对数比较，避免极小概率在直接计算指数时下溢；边界附近仍受浮点对数精度影响。温度输出转为浮点数，过大值可能溢出。本实现不等同于 [CASE-002](../../组合案例/CASE-002/CASE-002.md) 的第三方实现，后者设置最低温度。

**验证范围：** 2026-11-12 使用 [check_annealing_acceptance.py](check_annealing_acceptance.py) 核对改善、相等、较差、极端数值、降温和异常输入；另用直接指数概率比较 10,000 组确定性随机决策。未评价完整搜索的质量。本项目参考代码尚未单独声明开源许可。

**出处：** Stefan Røpke、David Pisinger, *An Adaptive Large Neighborhood Search Heuristic for the Pickup and Delivery Problem with Time Windows*，[2006 年发表版 MinerU 全文](../../../../../data/P1_calibration_papers/ALNS_2006_MinerU/full.md)第 3.5 节；[正式发表 DOI](https://doi.org/10.1287/trsc.1050.0135)。2026-11-12 核对解析正文、本地原 PDF 第 8 页（印刷页 462）的接受与降温公式，以及 CASE-002 所收录的第三方接受代码；未运行论文作者源码。论文还给出针对其问题的初始温度设置，本组件不默认采用该设置。
