# ALG-003：ALNS 自适应算子选择

算法正文和摘要见 [ALG-003.json](ALG-003.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [adaptive_operators.py](adaptive_operators.py) 是本项目参考论文独立实现的算子选择组件，不是论文作者源码，也不等同于 CASE-002 的第三方实现。使用 Python 3.13 标准库；`choose_operator` 根据权重与调用方提供的随机数源选择算子，`score_outcome` 计算本次奖励，`update_weights` 在阶段结束时更新权重。调用方独立选择移除与插入算子，并维护每个算子的调用次数、共享奖励及此前接受解的历史。

论文没有明确零次调用的权重处理，本实现选择保持原权重；不同奖励条件重叠时按新最优、改善、接受较差解的顺序计分。该优先级属于本实现约定。全部权重为零时选择函数报错，后续策略由调用方决定。代码文件版本和入口见 JSON 的 `code` 字段；本项目参考实现尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check_adaptive_operators.py](check_adaptive_operators.py) 检查轮盘边界、奖励条件、权重更新、零次调用和异常输入；另用 6000 个分层取值核对权重 1:2:3 的选择区间。该检查不评价完整 ALNS 搜索效果。

**出处：** Stefan Røpke、David Pisinger, *An Adaptive Large Neighborhood Search Heuristic for the Pickup and Delivery Problem with Time Windows*。[2005 年作者稿全文页面](https://www.researchgate.net/publication/220413334_An_Adaptive_Large_Neighborhood_Search_Heuristic_for_the_Pickup_and_Delivery_Problem_with_Time_Windows)第 3.3—3.4 节于 2026-11-07 核查；[2006 年发表版 MinerU 全文](../../../../../data/P1_calibration_papers/ALNS_2006_MinerU/full.md)第 3.3—3.4 节及原 PDF 表 1 于 2026-11-09 复核。两版未逐项对读；[发表信息与 DOI](https://orbit.dtu.dk/en/publications/an-adaptive-large-neighborhood-search-heuristic-for-the-pickup-an/)另行记录。未运行论文作者源码。
