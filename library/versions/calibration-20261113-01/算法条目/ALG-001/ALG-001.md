**参考代码：** [Split.cpp](hgs_split/Split.cpp) 和 [Split.h](hgs_split/Split.h) 来自作者的 [HGS-CVRP v1.0.0 固定提交](https://github.com/vidalt/HGS-CVRP/tree/35b32d8e9552074f52444d51ea1fe8aec9055467)。本目录还保存该组件所需的 `Params`、`Individual`、`CircleSector` 及[原始许可](hgs_split/LICENSE)。代码使用 C++11 和标准库；入口为 `Split::generalSplit`，依赖 HGS 的数据结构，并原地更新个体，不是独立接收需求数组的 Python 函数。调用前需保证车辆数、客户排列、索引和参数相容。

**验证范围：** 2026-11-12 核对案例引用的八个源码及许可文件与算法条目的哈希一致，并对作者的 `Split.cpp`、`Individual.cpp` 和 `Params.cpp` 执行 C++11 语法检查。[check_hgs_split.cpp](check_hgs_split.cpp) 链接上述作者代码，由原版 `Params` 读取[小型合成实例](check_hgs_split.vrp)；三个手算情形分别检查普通解码、有限车队回退与时长罚项。该测试不证明所有输入正确或验证完整 HGS 算法的性能。
