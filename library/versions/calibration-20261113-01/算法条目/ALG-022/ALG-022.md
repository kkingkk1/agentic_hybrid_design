# ALG-022：AllDifferent 匹配支持过滤

算法正文和摘要见 [ALG-022.json](ALG-022.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [all_different_gac.py](all_different_gac.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `all_different_gac`。输入有限域列表，输出每个变量有支持的值；不存在完整匹配时返回 None。只传播单个 AllDifferent 约束；重复匹配是项目参考实现，不等同于 Régin 的增量过滤实现。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：200 组有限域与全部互异赋值比较，包含 Hall 集和无解。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Marco Chiarandini，*Filtering Algorithms for Global Constraints*（南丹麦大学，2014 年课程讲义）：[来源原文](https://www.imada.sdu.dk/u/marco/DM826/Slides/dm826-lec9.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：南丹麦大学讲义中 AllDifferent、匹配与域一致性定义。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
