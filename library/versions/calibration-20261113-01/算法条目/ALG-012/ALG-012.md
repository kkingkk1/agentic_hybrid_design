# ALG-012：加权区间调度动态规划

算法正文和摘要见 [ALG-012.json](ALG-012.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [weighted_intervals.py](weighted_intervals.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `weighted_intervals`。输入开始、结束和权重三元组，输出最优权重及原下标；端点接触允许。每个区间须开始早于结束；只适用于单资源且无额外衔接约束的情况，负权重可不选。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：135 组小实例与全部子集比较，并检查端点接触和非法区间。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Srini Devadas、Erik Demaine、Nancy Lynch，*Design and Analysis of Algorithms, Lecture 1*（MIT，2015 年课程讲义）：[来源原文](https://ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms-spring-2015/ff2a7015ff913fc01f0381d8f5126a9a_MIT6_046JS15_lec01.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：MIT 6.046 讲义的 Weighted Interval Scheduling 及动态规划讨论。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
