# ALG-015：0/1 背包分支定界

算法正文和摘要见 [ALG-015.json](ALG-015.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [knapsack_branch_bound.py](knapsack_branch_bound.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `knapsack_branch_bound`。输入正整数重量、非负整数价值与容量，输出最大价值及所选原下标。只处理单容量 0/1 背包；不接受零重量，多维和其他约束须另行实现。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：200 组小背包与全部子集比较，并核查容量与物品集合。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Emory 课程材料 *Knapsack Branch and Bound*（作者和年份未核实）：[来源原文](https://www.cs.emory.edu/~cheung/Courses/253/Syllabus/BranchBound/Docs/Knapsack-branch+bound.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：讲义中 0/1 背包的 LP 松弛上界和分支定界。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
