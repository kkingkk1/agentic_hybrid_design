# ALG-004：Regret-k 请求插入

算法正文和摘要见 [ALG-004.json](ALG-004.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [regret_k.py](regret_k.py) 是本项目参考论文独立实现的插入组件，不是论文作者源码，也不等同于 CASE-002 的第三方实现。使用 Python 3.13 标准库；`regret_k_insert` 按路线计算请求的最优插入后，根据可用路线数量和 Regret-k 规则选择请求，直到没有可插入请求。无法插入的请求保留在返回结果中。

调用方必须提供 `best_insertion` 回调，由其计算每条路线中的最优可行插入，并负责取送货同车、先取后送、容量、时间窗和目标函数等约束。组件不自行检查回调返回的路线是否满足这些约束，也不新增路线。实现每次插入后重新计算候选，没有使用论文的选择性缓存更新。代码文件版本和入口见 JSON 的 `code` 字段；本项目参考实现尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check_regret_k.py](check_regret_k.py) 检查 Regret 值、可用路线不足时的优先级、平局、无法插入的请求和异常输入，并用含同车、先后顺序、容量及时间窗检查的小型取送货回调核对接口。示例不覆盖全部取送货约束，也不是性能基准。

**出处：** Stefan Røpke、David Pisinger, *An Adaptive Large Neighborhood Search Heuristic for the Pickup and Delivery Problem with Time Windows*。[2005 年作者稿全文页面](https://www.researchgate.net/publication/220413334_An_Adaptive_Large_Neighborhood_Search_Heuristic_for_the_Pickup_and_Delivery_Problem_with_Time_Windows)第 3.2.1—3.2.2 节于 2026-11-07 核查；[2006 年发表版 MinerU 全文](../../../../../data/P1_calibration_papers/ALNS_2006_MinerU/full.md)同节于 2026-11-10 复核。两版未逐项对读；[发表信息与 DOI](https://orbit.dtu.dk/en/publications/an-adaptive-large-neighborhood-search-heuristic-for-the-pickup-an/)另行记录。未运行论文作者源码。
