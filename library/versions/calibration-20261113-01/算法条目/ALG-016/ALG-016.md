# ALG-016：迭代加深深度优先搜索

算法正文和摘要见 [ALG-016.json](ALG-016.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [iterative_deepening.py](iterative_deepening.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `iterative_deepening`。输入邻接表、起点、终点和最大深度；返回路径，或在该深度范围内未找到时返回 None。只按边数比较，不处理不同边权；None 同时涵盖无解与超过上限。递归深度受 Python 栈限制。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：100 个小图与广度优先最短边数比较，并核查深度上限。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Dan Klein、Pieter Abbeel 等，*CS188 Search*（Berkeley，2026 年课程讲义）：[来源原文](https://inst.eecs.berkeley.edu/~cs188/sp26/assets/lectures/cs188-sp26-lec02.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：Berkeley CS188 讲义的 Iterative Deepening 与深度优先搜索。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
