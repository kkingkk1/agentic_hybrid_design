# ALG-020：前向检查的 CSP 回溯搜索

算法正文和摘要见 [ALG-020.json](ALG-020.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [csp_forward_checking.py](csp_forward_checking.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `solve_csp`。输入有限变量域和二元允许值对，输出一个变量赋值；穷尽后无解返回 None。只支持有限二元约束，不枚举所有解；递归深度受 Python 栈限制。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：100 组四变量 CSP 与全部赋值比较，并检查无解与空问题。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** CMU 15-281 课程材料 *Constraint Satisfaction Problems*（作者和年份未核实）：[来源原文](https://www.cs.cmu.edu/~15281/coursenotes/constraints/)。2026-11-12 通过 Exa 阅读相关正文节选：CMU CSP 讲义的回溯、前向检查和 MRV。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
