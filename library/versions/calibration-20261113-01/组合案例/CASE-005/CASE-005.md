# CASE-005：TSP 的蚁群与交替局部搜索

**案例文件：** [CASE-005.json](CASE-005.json) 使用四字段模板，代码由文件清单组装。

**问题与流程：** 先按最近邻路线长度初始化信息素，再由多只蚂蚁依据信息素和距离构造回路，并对经过的边做局部信息素更新。偶数轮对本轮最优蚂蚁做 2.5-opt，奇数轮对随机蚂蚁做 2-opt；找到严格更短路线时更新全局最好解，随后对其边做全局信息素更新。达到实例中的已知目标值、迭代上限或近似时间上限时停止。

**限制与迁移：** best_global_length 初始为最近邻长度，但 best_global_path 初始为全零数组。若蚂蚁与局部搜索均未严格改善最近邻长度，更新信息素及打印时使用的路线可能不是该长度对应的有效回路。`aco_solution` 返回路线长度，不返回路线；仅在 `print_path` 启用时打印路线。源码静态检查已确认这一初始化缺口；使用前须保存初始路线并独立核对打印路线的节点覆盖与路长。入口需要有效实例路径和原程序支持的实例格式。
