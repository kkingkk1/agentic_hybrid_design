# CASE-007：VRPTW 的车队缩减与大邻域搜索

**案例文件：** [CASE-007.json](CASE-007.json) 使用四字段模板，代码由文件清单组装。

**问题与流程：** 输入 Solomon 格式的带时间窗车辆路径实例，入口固定读取 100 个客户。贪心构造后先执行车队缩减：移除和重新插入客户，必要时对未服务请求调用 ejection search。随后选择破坏与修复操作，比较候选与最好解，并按实现中的接受和扩大移除范围规则继续搜索。主阶段修复选择器对 0 至 9 的随机数使用随机顺序插入，对其余数值使用 Regret-2；代码嵌套导致其他选择分支不可达。

**限制与迁移：** 车队缩减循环计数至 200000；主搜索计数至 500000，但空移除时会回退计数并重试，因此实际尝试次数不受该计数保证，极端情况下可能无法停止。入口直接读取命令行实例路径；案例未附实例。当候选不可行或路线数过多而提前拒绝时，偏差变量 dev 可能未赋值或仍是旧值，却用于后续停滞判断；首次发生时可能读取未初始化变量。代码使用 GCC 风格头文件，迁移时应核对时间窗、容量、请求覆盖和停止预算。

**验证范围：** 2026-11-12 使用 g++ -std=c++17 -fsyntax-only 检查全部 C++ 实现文件，通过语法检查；未链接或运行实例，也未验证约束正确性或性能。
