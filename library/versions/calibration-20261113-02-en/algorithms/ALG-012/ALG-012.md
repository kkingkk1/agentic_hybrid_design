# ALG-012: Weighted interval scheduling dynamic programming

See [ALG-012.json](ALG-012.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [weighted_intervals.py](weighted_intervals.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `weighted_intervals`. It accepts start, end, and weight triples and returns optimal weight and original indices; touching endpoints are allowed. Each interval must start before it ends. Only one resource without extra transition constraints is supported, and negative-weight intervals may be skipped. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 135 small instances were compared with all subsets, and touching endpoints and invalid intervals were checked. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Srini Devadas, Erik Demaine, and Nancy Lynch, *Design and Analysis of Algorithms, Lecture 1* (MIT course notes, 2015): [source](https://ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms-spring-2015/ff2a7015ff913fc01f0381d8f5126a9a_MIT6_046JS15_lec01.pdf).
