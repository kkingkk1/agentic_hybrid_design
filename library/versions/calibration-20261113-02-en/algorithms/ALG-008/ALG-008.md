# ALG-008: Shaw related-request removal

See [ALG-008.json](ALG-008.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [shaw_removal.py](shaw_removal.py) is a project removal component independently implemented from the paper, using the Python 3.13 standard library. `shaw_removal(routes, node_request, count, power, relatedness, rng)` returns new routes and removed requests. Routes contain visit nodes only; the mapping must cover exactly these nodes, and nodes of the same request must be in the same route. Inputs are not modified. A smaller `relatedness(a, b)` value indicates greater relatedness; the caller must supply stable values based on the state before removal.

For example, routes are `[["ap", "ad", "bp", "bd"], ["cp", "cd"]]`, and the nodes belong to requests `a`, `b`, and `c`, respectively. If `a` is selected first, `b` is more related than `c`, and the random index is zero, the result removes `a` and `b` and returns `[[], ["cp", "cd"]]` and `["a", "b"]`.

The component does not implement the paper's relatedness formula based on distance, time, demand, and vehicle compatibility, and cannot identify pickup or delivery nodes already missing from the mapping. The caller supplies the correct mapping, maintains the request bank, and checks feasibility. It is not the third-party code in [CASE-002](../../cases/CASE-002/CASE-002.md). The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check_shaw_removal.py](check_shaw_removal.py) checked grouped pickup-delivery removal, biased ranking, input preservation, and invalid inputs. Another 100 fixed-seed cases were compared against an independent selection procedure. Complete ALNS was not run and no performance benchmark was performed.

**Source:** Stefan Røpke and David Pisinger, *An Adaptive Large Neighborhood Search Heuristic for the Pickup and Delivery Problem with Time Windows*, section 3.1.1 and algorithm 2 of the [2006 published-version MinerU text](../../../../../data/P1_calibration_papers/ALNS_2006_MinerU/full.md); [published DOI](https://doi.org/10.1287/trsc.1050.0135). On 2026-11-12, the parsed text and third-party code included in CASE-002 were checked. Because MinerU omitted formatting from algorithm 2, the local original PDF page 6 (printed page 460) was also checked. The paper authors' code was not run.
