# ALG-023: Integer sum-equality support filtering

See [ALG-023.json](ALG-023.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [sum_gac.py](sum_gac.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `sum_equals_gac`. It accepts finite integer domains and an integer target, returning supported values for each domain or `None` if there is no complete supporting assignment. It handles a single equality over integer domains, including negative and discontinuous values, and does not propagate other constraints. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 200 sets of discrete integer domains were compared with all assignments, including empty domains, negative values, and gaps. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Marco Chiarandini, *Filtering Algorithms for Global Constraints* (University of Southern Denmark course notes, 2014): [source](https://www.imada.sdu.dk/u/marco/DM826/Slides/dm826-lec9.pdf). On 2026-11-12, relevant excerpts were read through Exa: the generalized-arc-consistency support definition. The project independently implements this special case using reachable-sum dynamic programming. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
