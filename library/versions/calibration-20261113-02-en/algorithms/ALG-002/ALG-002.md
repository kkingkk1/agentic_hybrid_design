# ALG-002: CVRP inter-route SWAP*

See [ALG-002.json](ALG-002.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [swap_star.py](swap_star.py) is a project component independently implemented from the paper; it is neither the authors' code nor the HGS code in CASE-001. It uses the Python 3.13 standard library. `swap_star_pair` accepts two specified customer routes, the distance matrix, demand, and capacity, and returns the best strictly improving route pair and objective change, or `None` if none exists. It supports hard capacity and an excess-capacity penalty; the latter may return routes that violate hard capacity. The implementation compares three precomputed insertion positions with the position created by removing the customer.

The component searches only the given route pair, not the complete solution, and does not use the paper's polar-sector route filter. It does not support extra constraints such as time windows or route duration. Checking only the best move after return cannot replace checking each candidate's extra constraints during enumeration. Finding the best move satisfying those constraints requires changing candidate checks. Floating-point inputs are treated as their exact binary values in rational arithmetic; floating-point outputs may round or overflow. Code version and entry point are in the JSON `code` field; the project reference implementation has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check_swap_star.py](check_swap_star.py) compared every exchanged customer and insertion position for 360 small route pairs and checked hand-calculated cases, no improvement, and invalid inputs. An independent exhaustive program additionally compared 100 small instances with directed distances and floating-point data. These checks are not a performance benchmark.

**Source:** Thibaut Vidal, *Hybrid Genetic Search for the CVRP: Open-Source Implementation and SWAP\* Neighborhood*, 2022; [author manuscript arXiv:2012.10384v2](https://arxiv.org/html/2012.10384v2), section 3, theorem 1, algorithm 2; [published DOI](https://doi.org/10.1016/j.cor.2021.105643). The text was checked on 2026-11-07 and section 3 of the manuscript HTML was rechecked on 2026-11-09. The authors' source code was not run.
