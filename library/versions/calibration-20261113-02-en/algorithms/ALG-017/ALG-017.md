# ALG-017: A* path-tree search

See [ALG-017.json](ALG-017.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [astar_tree.py](astar_tree.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `astar_tree`. It accepts a finite explicit graph, start, goal, and heuristic function and returns cost and path, or `None` if no path exists. All edge weights must be finite and nonnegative; heuristic values must be finite and nonnegative, the heuristic must be admissible, and the goal heuristic must be zero. The implementation checks only visited edges and called heuristic values; it cannot verify whole-graph nonnegativity or admissibility. Without a global closed set, states may be expanded repeatedly. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 80 small graphs were compared with exhaustive simple paths; nonzero admissible heuristics were also checked. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Dan Klein, Pieter Abbeel, et al., *CS188 Informed Search* (Berkeley course notes, 2026): [source](https://inst.eecs.berkeley.edu/~cs188/sp26/assets/lectures/cs188-sp26-lec03.pdf). On 2026-11-12, relevant excerpts were read through Exa: A*, admissible heuristics, and path-tree search in Berkeley CS188. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
