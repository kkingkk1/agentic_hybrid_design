# ALG-025: Lagrangian relaxation upper bound for knapsack

See [ALG-025.json](ALG-025.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [lagrangian_knapsack.py](lagrangian_knapsack.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `lagrangian_knapsack`. It accepts nonnegative weights, values, capacity, and a fixed multiplier and returns an upper bound and the relaxed-subproblem selection. It computes the bound for the given multiplier only and does not optimize it; the relaxed selection may exceed capacity and cannot be treated directly as feasible. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 180 small knapsacks were compared with all feasible subsets to check that the upper bound was no lower than the optimum. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.
