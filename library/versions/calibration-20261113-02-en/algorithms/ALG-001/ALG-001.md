# ALG-001: HGS-CVRP Split decoding

The algorithm's responsibility, interface, and limits are described in [ALG-001.json](ALG-001.json). The JSON, registered code, and this page together constitute one entry.

**Reference code:** [Split.cpp](hgs_split/Split.cpp) and [Split.h](hgs_split/Split.h) come from the authors' [fixed HGS-CVRP v1.0.0 commit](https://github.com/vidalt/HGS-CVRP/tree/35b32d8e9552074f52444d51ea1fe8aec9055467). This directory also contains `Params`, `Individual`, `CircleSector`, and the [original license](hgs_split/LICENSE) needed by the component. The code uses C++11 and its standard library. Its entry is `Split::generalSplit`, which depends on HGS data structures and updates an individual in place; it is not a standalone Python function accepting a demand array. Vehicle count, customer permutation, indices, and parameters must be compatible before the call.

The sources are stored only in this directory. The file manifest for [CASE-001](../../cases/CASE-001/CASE-001.json) references them by ID, path, and hash; the reader assembles them with case-specific files into the complete case. The code has an MIT license, copyright Thibaut Vidal; the accompanying copyright and license notices must be retained when copying or distributing it.

**Validation scope:** On 2026-11-12, the eight source and license files referenced by the case were checked against the algorithm entry's hashes, and the authors' `Split.cpp`, `Individual.cpp`, and `Params.cpp` passed C++11 syntax checks. [check_hgs_split.cpp](check_hgs_split.cpp) links that author code and uses the original `Params` to read a [small synthetic instance](check_hgs_split.vrp). Three hand-calculated cases check ordinary decoding, limited-fleet fallback, and duration penalties. These tests neither prove correctness for all inputs nor evaluate complete HGS performance.

**Historical calibration implementation:** [split.py](split.py) is an earlier independently written project implementation in Python with hard capacity and no vehicle-count limit; it differs from the currently registered author version. The historical checks in [check_split.py](check_split.py) apply only to that Python file. Both remain as historical references, are not in the current ALG-001 `code.files`, and are not loaded by the reader as this entry's reference implementation.

**Source:** The code version is the fixed HGS-CVRP v1.0.0 commit included in CASE-001. For method background, see Thibaut Vidal, *Technical Note: Split Algorithm in O(n) for the Capacitated Vehicle Routing Problem*, sections 1 and 3–4 and algorithms 2–3 in the [author manuscript arXiv:1508.02759v3](https://arxiv.org/html/1508.02759v3), and the [published DOI](https://doi.org/10.1016/j.cor.2015.11.012). The manuscript text was checked on 2026-11-07 and the specified sections of its HTML were rechecked on 2026-11-09. A notation ambiguity exists between line 4 of manuscript algorithm 2 and the later definition of $f$; the registered code is the authority for this entry's interface and implementation.
