# ALG-027: Knapsack cover-inequality separation

See [ALG-027.json](ALG-027.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [cover_cut.py](cover_cut.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `violated_cover`. It accepts nonnegative weights, capacity, and a point whose components lie between 0 and 1, returning one violated cover's item indices or `None`. It separates basic cover inequalities only; it does not automatically solve an LP or add cuts to a solver. `None` means only that no violation of that type was found. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 100 small knapsacks were compared with all subsets for the existence of a violated cover; found cuts were checked against every integer-feasible solution. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Illinois IE 511 course material, *Lecture 28: Column Generation, Knapsack Cover Inequalities* (2025; author unverified): [source](https://karthik.ise.illinois.edu/courses/ie511/lectures-sp-25/lecture-28.pdf). On 2026-11-12, relevant excerpts were read through Exa: definitions of knapsack covers and valid inequalities. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
