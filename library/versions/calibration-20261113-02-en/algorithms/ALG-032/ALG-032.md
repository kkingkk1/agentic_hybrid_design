# ALG-032: Edmonds–Karp maximum flow

See [ALG-032.json](ALG-032.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [edmonds_karp.py](edmonds_karp.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `edmonds_karp`. It accepts vertex count, directed edge capacities, and distinct source and sink, returning maximum-flow value and the residual-network set reachable from the source. Capacities must be nonnegative integers; parallel edges are merged. This implementation does not output per-edge flows or handle costs or multicommodity flow. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 100 small networks were compared with all source-sink cuts, including the capacity of the returned cut. Another 100 networks were compared with SciPy 1.17.1's maximum-flow implementation. That library was used only for validation and is not an implementation dependency. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Jack Edmonds and Richard M. Karp, *Theoretical Improvements in Algorithmic Efficiency for Network Flow Problems* (1972): [source](https://raw.githubusercontent.com/deltadbu/UCAS_algorithm_course/master/Lectures/EdmondsKarp1972.pdf). On 2026-11-12, relevant excerpts were read through Exa: the rule of using a minimum-arc-count augmenting path each time. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
