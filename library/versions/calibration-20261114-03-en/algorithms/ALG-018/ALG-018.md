# ALG-018: Layered beam search

See [ALG-018.json](ALG-018.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [beam_search.py](beam_search.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `beam_search`. It accepts an unweighted graph, start, goal, beam width, depth limit, and heuristic and returns a path or `None`. Width or depth limits may miss solutions, optimality is not guaranteed, and `None` does not prove infeasibility. Equal heuristic values follow generation order. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: A constructed counterexample checked that a narrow beam misses a solution while a wider beam finds it; depth and parameters were also checked. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Yuan Shen, *Tutorial 1: Rule-based Systems, Search* (MIT course material, 2010): [source](https://ocw.mit.edu/courses/6-034-artificial-intelligence-fall-2010/f0d6c16f941891b8a270b9b6f5358b98_MIT6_034F10_tutor01.pdf).
