# ALG-011: 0/1 knapsack capacity dynamic programming

See [ALG-011.json](ALG-011.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [knapsack_dp.py](knapsack_dp.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `knapsack_dp`. It accepts nonnegative integer weights, values, and capacity and returns maximum value and original item indices; zero weights are allowed. It handles only single-capacity 0/1 knapsack, with a potentially large table for large numeric capacity; multidimensional constraints are not handled. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 180 small knapsacks were compared with all subsets, including zero-weight items. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Erik Demaine, *Introduction to Algorithms, Lecture 21: Knapsack* (MIT course notes, 2011): [source](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/3484e876d81aba07911a1109f5b5e81e_MIT6_006F11_lec21.pdf). On 2026-11-12, relevant excerpts were read through Exa: MIT 6.006 knapsack states, recurrence, and pseudopolynomial complexity. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
