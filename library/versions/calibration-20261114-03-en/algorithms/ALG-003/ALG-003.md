# ALG-003: ALNS adaptive operator selection

See [ALG-003.json](ALG-003.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [adaptive_operators.py](adaptive_operators.py) is a project operator-selection component independently implemented from the paper; it is neither the authors' code nor the third-party implementation in CASE-002. It uses the Python 3.13 standard library. `choose_operator` selects an operator from weights and a caller-provided random source; `score_outcome` computes the current reward; `update_weights` updates weights at the end of a segment. The caller independently selects removal and insertion operators and maintains each operator's call count, shared rewards, and the history of previously accepted solutions.

The paper does not specify weight handling for zero calls, so this implementation retains the previous weight. When reward conditions overlap it scores, in order, a new best, an improvement, or acceptance of a worse solution; this precedence is an implementation choice. Selection raises an error when all weights are zero, and the caller decides the subsequent policy. Code version and entry point are in the JSON `code` field; the project reference implementation has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check_adaptive_operators.py](check_adaptive_operators.py) checked roulette boundaries, reward conditions, updates, zero calls, and invalid input. Another check used 6000 stratified values to verify selection intervals for weights 1:2:3. It did not evaluate complete ALNS search performance.
