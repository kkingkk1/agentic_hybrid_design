# ALG-020: CSP backtracking with forward checking

See [ALG-020.json](ALG-020.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [csp_forward_checking.py](csp_forward_checking.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `solve_csp`. It accepts finite variable domains and binary allowed pairs, returning one assignment or `None` after exhaustive search. Only finite binary constraints are supported, and it does not enumerate all solutions; recursion depth is limited by the Python stack. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 100 four-variable CSPs were compared with all assignments, including infeasible and empty problems. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** CMU 15-281 course material, *Constraint Satisfaction Problems* (author and year unverified): [source](https://www.cs.cmu.edu/~15281/coursenotes/constraints/). On 2026-11-12, relevant excerpts were read through Exa: backtracking, forward checking, and MRV in the CMU CSP notes. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
