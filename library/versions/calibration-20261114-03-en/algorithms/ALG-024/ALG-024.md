# ALG-024: Fractional knapsack linear relaxation

See [ALG-024.json](ALG-024.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [fractional_knapsack.py](fractional_knapsack.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `fractional_knapsack`. It accepts positive weights, nonnegative values, and nonnegative capacity and returns the exact relaxation objective and each item's fraction. It applies only to one capacity, divisible items, and nonnegative values; it can upper-bound 0/1 knapsack but need not be an integer-feasible solution. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 140 small instances were compared with enumeration of fractional-polytope vertices, and capacity was checked. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Emory course material, *Knapsack Branch and Bound* (author and year unverified): [source](https://www.cs.emory.edu/~cheung/Courses/253/Syllabus/BranchBound/Docs/Knapsack-branch+bound.pdf). On 2026-11-12, relevant excerpts were read through Exa: fractional knapsack relaxation, value density, and upper bounds for integer knapsack. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
