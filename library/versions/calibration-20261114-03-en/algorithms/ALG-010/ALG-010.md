# ALG-010: Held–Karp subset dynamic programming for TSP

See [ALG-010.json](ALG-010.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [held_karp.py](held_karp.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `held_karp`. It accepts a finite numeric square matrix and a start vertex, returning optimal tour cost and a vertex sequence with the start at both ends. A complete directed matrix is required; negative edges are supported, but missing edges, capacity, and time windows are not. A single-vertex tour has zero cost. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 72 small directed instances were compared with exhaustive permutations, including single-vertex and invalid inputs. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** David Eppstein, *Exact TSP Algorithm* (UCI course notes, 2026): [source](https://ics.uci.edu/~eppstein/163/lecture5b.pdf). On 2026-11-12, relevant excerpts were read through Exa: the UCI graph-algorithms notes' TSP subset states, recurrence, and reconstruction. The notes list the original Bellman and Held–Karp papers. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
