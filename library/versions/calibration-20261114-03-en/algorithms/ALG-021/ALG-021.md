# ALG-021: Generalized arc consistency for a table constraint

See [ALG-021.json](ALG-021.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [table_gac.py](table_gac.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `table_gac`. It accepts finite domains and explicitly allowed tuples, returning supported domains or `None` when no valid tuple exists. It handles a single positive table constraint; the caller manages other constraints and overall propagation, and the result does not prove a multi-constraint problem feasible. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 100 small allowed tables were compared with direct support enumeration, including empty tables and arity checks. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Marco Chiarandini, *Filtering Algorithms for Global Constraints* (University of Southern Denmark course notes, 2014): [source](https://www.imada.sdu.dk/u/marco/DM826/Slides/dm826-lec9.pdf). On 2026-11-12, relevant excerpts were read through Exa: generalized arc consistency and tuple-support definitions. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
