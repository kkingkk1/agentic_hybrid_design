# ALG-013: Shortest-path dynamic programming on a directed acyclic graph

See [ALG-013.json](ALG-013.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [dag_paths.py](dag_paths.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `dag_shortest_paths`. It accepts vertex count, directed edges, and start and returns distances and predecessors; unreachable vertices are `None` and edge weights may be negative. The entire input graph must be acyclic; even an unreachable cycle raises an error. It does not solve resource-constrained paths. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 140 small DAGs were compared with path enumeration, including negative edges, unreachable vertices, and cycles. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Srini Devadas, *Introduction to Algorithms, Lecture 16: Dijkstra* (MIT course notes, 2011): [source](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/6277a1f06100c26a7ff21031af6757b5_MIT6_006F11_lec16.pdf). On 2026-11-12, relevant excerpts were read through Exa: MIT 6.006 topological sorting for DAGs and edge relaxation. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
