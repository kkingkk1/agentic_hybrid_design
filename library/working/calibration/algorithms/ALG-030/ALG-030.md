# ALG-030: Bellman–Ford shortest paths with negative edges

See [ALG-030.json](ALG-030.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [bellman_ford.py](bellman_ford.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `bellman_ford`. It accepts vertex count, finite edge weights, and start and returns distances and predecessors; a negative cycle reachable from the start raises an error. It reports only reachable negative cycles; unreachable negative cycles do not affect the result. On detecting a negative cycle it does not return per-vertex negative-infinity labels. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 100 DAGs with negative edges were compared with path enumeration, and reachable and unreachable negative cycles were distinguished. Another 120 nonnegative-weight graphs were compared with SciPy 1.17.1's Floyd–Warshall implementation; the entry's DAG enumeration remains the check for negative edges. SciPy was used only for validation. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Erik Demaine, Jason Ku, and Justin Solomon, *Introduction to Algorithms, Lecture 12: Bellman–Ford* (MIT course notes, 2020): [source](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/2430d7903a5529451d80c17f89a41fe8_MIT6_006S20_lec12.pdf). On 2026-11-12, relevant excerpts were read through Exa: the MIT 6.006 notes' negative edges, relaxation, and reachable negative cycles. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
