# ALG-029: Dijkstra shortest paths with nonnegative weights

See [ALG-029.json](ALG-029.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [dijkstra.py](dijkstra.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `dijkstra`. It accepts vertex count, weighted directed edges, and start and returns distances and predecessors; unreachable vertices are `None`. All edge weights must be finite and nonnegative. It solves shortest paths only and does not handle vehicle capacity, time windows, or multiple resource constraints. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 80 small nonnegative graphs were compared with Floyd–Warshall, and unreachable negative edges were rejected. Another 120 nonnegative-weight graphs were compared with SciPy 1.17.1's Floyd–Warshall implementation. That library was used only for validation and is not an implementation dependency. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Erik Demaine, Jason Ku, and Justin Solomon, *Introduction to Algorithms, Lecture 13: Dijkstra’s Algorithm* (MIT course notes, 2020): [source](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/d819e7f4568aced8d5b59e03db6c7b67_MIT6_006S20_lec13.pdf). On 2026-11-12, relevant excerpts were read through Exa: the MIT 6.006 notes' nonnegative-weight condition and relaxation. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
