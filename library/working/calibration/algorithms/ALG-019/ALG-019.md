# ALG-019: AC-3 binary arc consistency

See [ALG-019.json](ALG-019.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [ac3.py](ac3.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `ac3`. It accepts a mapping from variables to finite domains and binary allowed-pair constraints, returning new filtered domains or `None` when a domain becomes empty. Only finite binary constraints are supported; constraints on the same variable pair are intersected. Arc consistency does not guarantee a solution to the complete CSP. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 100 small constraint networks were compared with all assignments to check that feasible solutions were not removed and the outputs were arc-consistent. Chained propagation, empty domains, and a three-variable counterexample that is locally consistent but globally infeasible were also checked. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Alan K. Mackworth, *Consistency in Networks of Relations* (Artificial Intelligence, 1977): [source](https://www.cs.ubc.ca/~mack/Publications/AI77.pdf). On 2026-11-12, relevant excerpts were read through Exa: REVISE and the AC-3 queue algorithm in Mackworth's 1977 paper. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
