# ALG-016: Iterative-deepening depth-first search

See [ALG-016.json](ALG-016.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [iterative_deepening.py](iterative_deepening.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `iterative_deepening`. It accepts an adjacency list, start, goal, and maximum depth and returns a path or `None` when no path is found within the limit. It compares edge counts only, not differing edge weights; `None` covers both infeasibility and a solution beyond the limit. Recursion depth is restricted by the Python stack. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 100 small graphs were compared with breadth-first shortest edge counts, and the depth limit was checked. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Dan Klein, Pieter Abbeel, et al., *CS188 Search* (Berkeley course notes, 2026): [source](https://inst.eecs.berkeley.edu/~cs188/sp26/assets/lectures/cs188-sp26-lec02.pdf). On 2026-11-12, relevant excerpts were read through Exa: iterative deepening and depth-first search in Berkeley CS188. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
