# ALG-005: 2-Opt local improvement for symmetric TSP

See [ALG-005.json](ALG-005.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [two_opt.py](two_opt.py) is an independently implemented project 2-Opt component, not the paper authors' code. It uses the Python 3.13 standard library. `two_opt` accepts a complete permutation without a repeated start and a symmetric nonnegative distance matrix. It repeatedly chooses the best strictly improving move until no legal improvement remains, then returns closed-tour length and the improved permutation.

The implementation does not handle asymmetric distances, capacity, time windows, or a solve-time limit. Floating-point inputs are treated as their exact binary values in rational arithmetic; floating-point outputs may round or overflow. Code version and entry point are in the JSON `code` field; the project reference implementation has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check_two_opt.py](check_two_opt.py) checked crossing paths, invalid input, and every legal neighbor in 150 random small symmetric instances; an independent rational-cost calculation checked another 120 small instances. This is not a performance benchmark.

**Source:** Ulrich A. Brodowsky and Stefan Hougardy, *The Approximation Ratio of the 2-Opt Heuristic for the Euclidean Traveling Salesman Problem*. Sections 1–2 of the [author manuscript arXiv:2010.02583v3](https://arxiv.org/html/2010.02583v3) were checked on 2026-11-07; the definitions and algorithm on PDF pages 3–4 of the [STACS 2021 published PDF](../../../../../data/P1_calibration_papers/two_opt_brodowsky_hougardy_stacs_2021.pdf) were rechecked on 2026-11-10. The versions were not compared item by item. The paper was used to check the operator definition and the Euclidean problem boundary, not as a source for the first proposal. The authors' code was not run.
