# ALG-026: Primal simplex with a feasible origin

See [ALG-026.json](ALG-026.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [primal_simplex.py](primal_simplex.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `primal_simplex`. It accepts matrix A, nonnegative right-hand side b, and objective c and maximizes $c^\top x$ subject to $Ax\le b$ and $x\ge 0$. A bounded optimum returns `("optimal", optimal_value, solution_vector)`; an unbounded problem returns `("unbounded", None, None)`. It requires nonnegative b and supports only less-than-or-equal constraints and nonnegative variables; it does not implement two-phase simplex, integer constraints, or general model conversion. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 100 bounded two-dimensional LPs were compared with vertex enumeration; unbounded cases and invalid initial bases were also checked. Another 200 bounded linear programs were compared with the SciPy 1.17.1 HiGHS solver. That library was used only for validation and is not an implementation dependency. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Stanford MS&E 310 course material, *The Simplex Method* (author and year unverified): [source](https://web.stanford.edu/class/msande310/lecture09.pdf). On 2026-11-12, relevant excerpts were read through Exa: feasible bases, minimum ratio, unboundedness, and Bland's rule. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
