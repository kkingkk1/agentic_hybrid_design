# ALG-015: 0/1 knapsack branch and bound

See [ALG-015.json](ALG-015.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [knapsack_branch_bound.py](knapsack_branch_bound.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `knapsack_branch_bound`. It accepts positive integer weights, nonnegative integer values, and capacity, returning maximum value and original indices. It handles single-capacity 0/1 knapsack only, rejects zero weights, and requires separate handling of multidimensional and other constraints. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 200 small knapsacks were compared with all subsets, with checks on capacity and the selected item set. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Emory course material, *Knapsack Branch and Bound* (author and year unverified): [source](https://www.cs.emory.edu/~cheung/Courses/253/Syllabus/BranchBound/Docs/Knapsack-branch+bound.pdf). On 2026-11-12, relevant excerpts were read through Exa: the LP-relaxation upper bound and branch and bound for 0/1 knapsack. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
