# ALG-028: Hungarian minimum-cost assignment

See [ALG-028.json](ALG-028.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [hungarian.py](hungarian.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `hungarian`. It accepts a finite cost matrix with no more rows than columns and returns minimum cost and each row's assigned column index. Only complete cost matrices are supported; negative costs are allowed, while unavailable edges, extra capacities, and route constraints require separate modeling. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: Several small rectangular matrices were compared with full permutation enumeration, including negative costs and invalid dimensions. Another 300 rectangular matrices were compared with SciPy 1.17.1's linear assignment solver. That library was used only for validation and is not an implementation dependency. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Columbia IEOR 8100 course material, *Lecture 6: The Hungarian Algorithm* (2012; author unverified): [source](https://www.columbia.edu/~cs2035/courses/ieor8100.F12/lec6.pdf). On 2026-11-12, relevant excerpts were read through Exa: dual potentials, zero reduced costs, and matching augmentation. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
