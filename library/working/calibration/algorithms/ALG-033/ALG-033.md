# ALG-033: Hopcroft–Karp maximum bipartite matching

See [ALG-033.json](ALG-033.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [hopcroft_karp.py](hopcroft_karp.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `hopcroft_karp`. It accepts counts of left and right vertices and bipartite edges and returns matching pairs with no shared endpoints. It optimizes cardinality only, not edge weights or extra capacities; recursion depth is limited by the Python stack. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 100 small bipartite graphs were compared with all assignment enumerations, checking edge and endpoint uniqueness. Another 100 graphs were compared with SciPy 1.17.1's bipartite-matching implementation. That library was used only for validation and is not an implementation dependency. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** John E. Hopcroft and Richard M. Karp, *An $n^{5/2}$ Algorithm for Maximum Matchings in Bipartite Graphs* (1973): [source](http://cse.unl.edu/~choueiry/Documents/MaxMatching-HopdcroftKarp.pdf); [DOI](https://doi.org/10.1137/0202019). On 2026-11-12, relevant excerpts were read through Exa: staged matching with shortest augmenting paths. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
