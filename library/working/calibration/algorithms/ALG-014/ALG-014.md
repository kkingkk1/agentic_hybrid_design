# ALG-014: Depth-first branch and bound for TSP

See [ALG-014.json](ALG-014.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [tsp_branch_bound.py](tsp_branch_bound.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `tsp_branch_bound`. It accepts a finite nonnegative distance matrix and a start, returning the exact shortest-tour cost and vertex sequence. Only complete graphs, nonnegative distances, and a single tour are supported; capacity, time windows, and missing edges are not handled, and worst-case enumeration can be extensive. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 72 small directed TSP instances were compared with all permutations, including a single vertex and rejection of negative edges. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Jon Bentley, *Tuning a TSP Algorithm* (MIT course notes, 2018): [source](https://ocw.mit.edu/courses/6-172-performance-engineering-of-software-systems-fall-2018/dd989b76928a0561851e73da6d028763_MIT6_172F18_lec21.pdf).
