# ALG-022: AllDifferent matching-support filtering

See [ALG-022.json](ALG-022.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [all_different_gac.py](all_different_gac.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `all_different_gac`. It accepts a list of finite domains and returns the supported values for each variable, or `None` if no complete matching exists. It propagates one AllDifferent constraint only; the project's repeated-matching reference implementation is not Régin's incremental filtering implementation. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 200 sets of finite domains were compared with all distinct assignments, including Hall sets and infeasibility. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Marco Chiarandini, *Filtering Algorithms for Global Constraints* (University of Southern Denmark course notes, 2014): [source](https://www.imada.sdu.dk/u/marco/DM826/Slides/dm826-lec9.pdf). On 2026-11-12, relevant excerpts were read through Exa: the notes' definitions of AllDifferent, matching, and domain consistency. The complete source was not read page by page. The code was independently implemented by the project; its interface, adaptations, limits, and actual cost are as stated in the JSON and code.
