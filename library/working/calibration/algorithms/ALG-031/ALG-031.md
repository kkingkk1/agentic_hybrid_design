# ALG-031: Kruskal minimum spanning tree

See [ALG-031.json](ALG-031.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [kruskal.py](kruskal.py) is a project implementation independently written with the Python 3.13 standard library; its entry point is `kruskal`. It accepts vertex count and weighted undirected edges and returns the minimum tree's total weight and edges, or `None` if disconnected. Negative weights and parallel edges are allowed; the result is a spanning tree, not a TSP tour. An empty graph yields zero weight and no edges. Numeric results use Python `Fraction`; floating-point inputs are converted according to their binary values. The project reference code has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check.py](check.py) performed these checks: 80 small undirected graphs were compared with all spanning-tree candidates, including negative edges and disconnected graphs. These small-scale checks are neither a performance benchmark nor a proof of correctness for all inputs.

**Source and inspection:** Dana Moshkovitz, Bruce Tidor, and Ben Zinberg, *Design and Analysis of Algorithms: Complete Lecture Notes* (MIT, 2012): [source](https://ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms-spring-2012/b1e5ac3c8f7d60db9b8d5b66c40bc55e_MIT6_046JS12_Notes.pdf).
