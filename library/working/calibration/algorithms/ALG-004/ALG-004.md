# ALG-004: Regret-k request insertion

See [ALG-004.json](ALG-004.json) for the algorithm description and summary. The JSON, code, and source record on this page together constitute one entry.

**Reference code:** [regret_k.py](regret_k.py) is a project insertion component independently implemented from the paper; it is neither the authors' code nor the third-party implementation in CASE-002. It uses the Python 3.13 standard library. `regret_k_insert` computes a request's best insertion by route and chooses requests according to available route counts and the Regret-k rule until no request can be inserted. Uninsertable requests remain in the return value.

The caller must provide a `best_insertion` callback to compute the best feasible insertion in each route and handle pickup-delivery same-vehicle assignment, precedence, capacity, time windows, and the objective. The component neither checks whether callback routes satisfy those constraints nor adds routes. It recalculates candidates after every insertion rather than using the paper's selective cache updates. Code version and entry point are in the JSON `code` field; the project reference implementation has no separately declared open-source license.

**Validation scope:** On 2026-11-12, [check_regret_k.py](check_regret_k.py) checked regret values, priority when fewer routes are available, ties, uninsertable requests, and invalid input. A small pickup-delivery callback checked the interface with same-vehicle, precedence, capacity, and time-window checks. The example does not cover all pickup-delivery constraints and is not a performance benchmark.

**Source:** Stefan Røpke and David Pisinger, *An Adaptive Large Neighborhood Search Heuristic for the Pickup and Delivery Problem with Time Windows*. Sections 3.2.1–3.2.2 of the [2005 author manuscript](https://www.researchgate.net/publication/220413334_An_Adaptive_Large_Neighborhood_Search_Heuristic_for_the_Pickup_and_Delivery_Problem_with_Time_Windows) were checked on 2026-11-07; the same sections of the [2006 published-version MinerU text](../../../../../data/P1_calibration_papers/ALNS_2006_MinerU/full.md) were rechecked on 2026-11-10.
