# ALG-049

Parallel Clarke–Wright savings merges depot routes at compatible ends under hard CVRP capacity.

The entry records the interface, reference code and exact implementation hash. This is an independent project reference using the Python 3.13 standard library. [ALG-049.json](ALG-049.json) · [savings.py](savings.py)

## Source and scope

The relevant excerpts or source files were inspected for the indicated mechanism. The Python adaptation and its operating boundaries are documented in the entry.

- The central-depot route-construction paper record. [Clarke and Wright, Scheduling of Vehicles from a Central Depot to a Number of Delivery Points (1964)](https://pubsonline.informs.org/doi/10.1287/opre.12.4.568)
- Section 6.4.12 and algorithm 6.7 on computing savings and joining compatible route ends. [Larson and Odoni, Urban Operations Research](https://web.mit.edu/urban_or_book/www/book/chapter6/6.4.12.html)

## Validation

Small CVRP trials checked successful merges, complete coverage and individual route loads. Checks used CPython 3.13.12 and small fixtures on 2026-11-18.
