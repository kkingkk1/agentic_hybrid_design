# ALG-057

Restricted set partitioning selects a minimum-distance disjoint cover from already feasible depot routes.

The entry records the interface, reference code and exact implementation hash. This is an independent project reference using the Python 3.13 standard library. [ALG-057.json](ALG-057.json) · [route_partition.py](route_partition.py)

## Source and scope

The relevant excerpts or source files were inspected for the indicated mechanism. The Python adaptation and its operating boundaries are documented in the entry.

- The combination of a heuristic route pool and set partitioning. [Subramanian, Uchoa and Ochi, A Hybrid Algorithm for a Class of Vehicle Routing Problems (2013)](https://luizsatoru.github.io/conteudo/artigos/COR2013-ANAND.pdf)
- The route-column formulation, pricing feedback and partial reoptimization illustrations. [Ruslan Sadykov, Practical Relevance of the State-of-the-Art Exact VRP Solvers (DIMACS 2023)](https://www.math.u-bordeaux.fr/~rsadykov/slides/Sadykov_DIMACS23slides.pdf)
