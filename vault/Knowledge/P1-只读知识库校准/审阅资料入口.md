# 校准样例审阅资料入口

本页帮助外部审阅者阅读七条校准样例的来源，并查看 PaperBanana 的参考库。它不改变样例的入库状态，也不代表外部审阅者已经读过论文或核实样例。

## 四篇论文与样例的对应关系

七条样例引用了四篇不同论文。以下链接优先指向样例实际使用的版本。

- **ALG-001：Split。** Thibaut Vidal, *Technical Note: Split Algorithm in O(n) for the Capacitated Vehicle Routing Problem*。[arXiv 作者稿 v3 全文](https://arxiv.org/html/1508.02759v3)，主要查看第 1—4 节。此版本正文注明 CC BY-NC-ND 4.0，阅读和使用时需遵守其条件。
- **ALG-002、CASE-001：HGS-CVRP 和 SWAP\*。** Thibaut Vidal, *Hybrid Genetic Search for the CVRP: Open-Source Implementation and SWAP\* Neighborhood*。[arXiv 作者稿 v2 全文](https://arxiv.org/html/2012.10384v2)，主要查看第 2—4 节。论文与代码的许可应分别核查。
- **ALG-003、ALG-004、CASE-002：ALNS。** Stefan Røpke 和 David Pisinger, *An Adaptive Large Neighborhood Search Heuristic for the Pickup and Delivery Problem with Time Windows*。[作者公开的 2005 年稿全文页面](https://www.researchgate.net/publication/220413334_An_Adaptive_Large_Neighborhood_Search_Heuristic_for_the_Pickup_and_Delivery_Problem_with_Time_Windows)，主要查看第 1—3.5 节；[DTU 发表信息](https://orbit.dtu.dk/en/publications/an-adaptive-large-neighborhood-search-heuristic-for-the-pickup-an/)记录正式出版信息。能否读取全文取决于访问通道。
- **ALG-005：2-Opt。** Ulrich A. Brodowsky 和 Stefan Hougardy, *The Approximation Ratio of the 2-Opt Heuristic for the Euclidean Traveling Salesman Problem*。[arXiv 作者稿 v3 全文](https://arxiv.org/html/2010.02583v3)，主要查看第 1—2 节；另有[会议发表版本](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.STACS.2021.18)。

2026-11-08 在 Zotero Web API 中按题名及作者检索，并按文件名检查本机资料库和当前项目材料，未找到这四篇论文的本地 PDF。这里提供论文原站链接，不把网页可读等同于允许任意再分发全文，也不声称已经检查本机所有位置。

## PaperBanana 参考库

[PaperBananaBench 参考资料](../../../data/PaperBanana/README.md)是从本机已有数据整理的审阅副本，包含 `diagram` 和 `plot` 两份原始 `ref.json`、全部 538 张对应参考图，以及便于分段读取的 JSON。副本与本项目的算法库、案例库分开。

本机数据没有包含这些图各自对应的论文 PDF。[上游提供了独立的 PDF 数据集](https://huggingface.co/datasets/dwzhu/PaperBananaDiagramPDFs)；它不包含在本仓库中，具体论文的访问与使用条件需另行核查。

## 给审阅者的建议

1. 先读[入库口径与七条样例](入库口径与校准说明.md)，再按上面的对应关系阅读论文所列章节。
2. 查看 PaperBanana 的原始 `ref.json` 或分卷，以及对应图片，再比较其字段和检索用途。
3. 分别列出实际读过的文件、论文版本和章节。无法读取的材料应明确标注；不能因为本页提供了链接就声称已经完成核查。
