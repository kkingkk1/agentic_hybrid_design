# 校准样例审阅资料入口

本页提供早期九条算法样例和前两个案例的论文资料，并帮助审阅者查看 PaperBanana 的参考库。新增算法与案例样例的来源入口见[分类清单](入库口径与校准说明.md)。本页不改变样例入库状态，也不代表审阅者已经核实材料。

## 四篇论文与早期样例的对应关系

ALG-001 至 ALG-009 与 CASE-001、CASE-002 引用或关联了四篇不同论文。以下链接指向这些早期样例使用或补充复核的版本；实际核查日期和范围以条目出处为准。ALG-010 至 ALG-033 和 CASE-003 至 CASE-010 使用其他来源，逐条记录在各自目录中。

- **ALG-001：Split。** Thibaut Vidal, *Technical Note: Split Algorithm in O(n) for the Capacitated Vehicle Routing Problem*。[本仓库的 arXiv 作者稿 v3 PDF](../../../data/P1_calibration_papers/split_vidal_arxiv_v3.pdf)，也可阅读[原站 HTML](https://arxiv.org/html/1508.02759v3)，主要查看第 1—4 节。此版本正文注明 CC BY-NC-ND 4.0，阅读和使用时需遵守其条件。
- **ALG-001、ALG-002、ALG-006、CASE-001：HGS-CVRP、Split、SWAP\* 和 OX。** Thibaut Vidal, *Hybrid Genetic Search for the CVRP: Open-Source Implementation and SWAP\* Neighborhood*。[本仓库的 MinerU 解析全文](../../../data/P1_calibration_papers/HGS_MinerU/full.md)来自 [arXiv 作者稿 v2](https://arxiv.org/html/2012.10384v2)，主要查看第 2—4 节。[作者 v1.0.0 代码的入池判断](https://github.com/vidalt/HGS-CVRP/blob/35b32d8e9552074f52444d51ea1fe8aec9055467/Program/Genetic.cpp#L11-L18)与论文伪代码有一处条件差异，见 [CASE-001](../../../library/working/calibration/cases/CASE-001/CASE-001.md)。OX 实现的边界差异见 [ALG-006](../../../library/working/calibration/algorithms/ALG-006/ALG-006.md)。公式、图表和版式应与原文核对。
- **ALG-003、ALG-004、ALG-007—ALG-009：ALNS；CASE-002 的背景文献。** Stefan Røpke 和 David Pisinger, *An Adaptive Large Neighborhood Search Heuristic for the Pickup and Delivery Problem with Time Windows*。[本仓库的 2006 年期刊发表版 MinerU 解析全文](../../../data/P1_calibration_papers/ALNS_2006_MinerU/full.md)可供审阅，主要查看第 1—3.5 节及第 3.8 节的最终解要求。CASE-002 现采用第三方 ALNS + CP-SAT 实现，差异和限制见[案例说明](../../../library/working/calibration/cases/CASE-002/CASE-002.md)；不能把它视为论文作者代码。公式、表格和图片需与原文核对。
  - **较早样例最初核查的版本：** ALG-003、ALG-004 和 CASE-002 最初使用的 [2005 年作者稿全文页面](https://www.researchgate.net/publication/220413334_An_Adaptive_Large_Neighborhood_Search_Heuristic_for_the_Pickup_and_Delivery_Problem_with_Time_Windows)和 [Academia 网页全文](https://www.academia.edu/60687015/An_adaptive_large_neighborhood_search_heuristic_for_the_pickup_and_delivery_problem_with_time_windows)是阅读入口；2005 年稿 PDF 的自动下载返回 HTTP 403。2006 年发表版不是该作者稿，审阅时请区分版本。
  - **较早版本：** 哥本哈根大学公开的 [2004 年技术报告 PDF](https://di.ku.dk/forskning/Publikationer/tekniske_rapporter/tekniske-rapporter-2004/04-13.pdf)共 29 页。它早于样例所用的 2005 年作者稿，阅读时应明确区分版本。
- **ALG-005：2-Opt。** Ulrich A. Brodowsky 和 Stefan Hougardy, *The Approximation Ratio of the 2-Opt Heuristic for the Euclidean Traveling Salesman Problem*。[本仓库的 STACS 2021 发表版 PDF](../../../data/P1_calibration_papers/two_opt_brodowsky_hougardy_stacs_2021.pdf)使用 CC BY 4.0，主要查看第 1—2 节；另有[提取文字版](../../../data/P1_calibration_papers/two_opt_brodowsky_hougardy_stacs_2021.txt)，公式和版式以 PDF 为准。原样例引用的是较早的 [arXiv 作者稿 v3](https://arxiv.org/html/2010.02583v3)；核查时请区分两个版本。

2026-11-08，研究者确认已取得 HGS 作者稿和 ALNS 2005 年作者稿全文及其 MinerU 解析文本的公开发布授权。2026-11-09，研究者另行确认已取得公开发布 ALNS 2006 年发表版 MinerU 全文的授权。仓库收录了 HGS 作者稿及 ALNS 发表版的解析资料；2005 年作者稿的 MinerU 版本仍未取得。Split 作者稿和 2-Opt 发表版的原样 PDF 也已提供，详见[论文来源及许可](../../../data/P1_calibration_papers/README.md)。

三十三条算法样例和十条案例样例均由[入库口径中的清单](入库口径与校准说明.md)链接至 JSON 正文及对应来源记录。算法均有参考实现；CASE-001 引用 ALG-001 中唯一保存的作者 Split 源码，其余算法的参考实现由本项目独立编写。适用范围及验证记录见各自来源说明。十个案例的四字段 JSON 均登记实现文件清单，读取器核对哈希后返回案例代码。实际来源、许可、本地改动和已知限制见各案例说明；部分案例存在已知缺陷或尚未完整运行。小规模运行不等于完成性能评价。

## PaperBanana 参考库

[PaperBananaBench 参考资料](../../../data/PaperBanana/README.md)是从本机已有数据整理的审阅副本，包含 `diagram` 和 `plot` 两份原始 `ref.json`、全部 538 张对应参考图，以及便于分段读取的 JSON。副本与本项目的算法库、案例库分开。

本机数据没有包含这些图各自对应的论文 PDF。[上游提供了独立的 PDF 数据集](https://huggingface.co/datasets/dwzhu/PaperBananaDiagramPDFs)；它不包含在本仓库中，具体论文的访问与使用条件需另行核查。

## 给审阅者的建议

1. 先读[入库口径与样例清单](入库口径与校准说明.md)，再按条目来源记录阅读相应章节。
2. 查看 PaperBanana 的原始 `ref.json` 或分卷，以及对应图片，再比较其字段和检索用途。
3. 分别列出实际读过的文件、论文版本和章节。无法读取的材料应明确标注；不能因为本页提供了链接就声称已经完成核查。
