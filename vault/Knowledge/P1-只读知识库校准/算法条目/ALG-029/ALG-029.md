# ALG-029：Dijkstra 非负最短路径

算法正文和摘要见 [ALG-029.json](ALG-029.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [dijkstra.py](dijkstra.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `dijkstra`。输入顶点数、有向加权边及起点，输出距离和前驱；不可达顶点为 None。所有边权须有限非负；只求最短路，不处理车辆容量、时间窗或多资源约束。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：80 组非负小图与 Floyd–Warshall 比较，并拒绝不可达负边。另与 SciPy 1.17.1 的 Floyd–Warshall 比较 120 个非负权图；该库仅用于验证，不是参考实现依赖。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Erik Demaine、Jason Ku、Justin Solomon，*Introduction to Algorithms, Lecture 13: Dijkstra’s Algorithm*（MIT，2020 年课程讲义）：[来源原文](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/d819e7f4568aced8d5b59e03db6c7b67_MIT6_006S20_lec13.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：MIT 6.006 Dijkstra 讲义的非负权条件与松弛。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
