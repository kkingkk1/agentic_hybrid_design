# ALG-002：CVRP 跨路线 SWAP*

算法正文和摘要见 [ALG-002.json](ALG-002.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [swap_star.py](swap_star.py) 是本项目参考论文独立实现的组件，不是论文作者源码，也不是 CASE-001 中的 HGS 源码。使用 Python 3.13 标准库；`swap_star_pair` 接收指定的两条客户路线、距离矩阵、需求及容量，返回最佳严格改善的路线对和目标变化；没有改善则返回 `None`。它支持硬容量及超容量罚项；后者的返回路线不一定满足硬容量。实现比较预计算的前三个插入位置和移除客户后形成的新位置。

该组件只搜索给定路线对，不遍历完整方案，也不采用论文的极角扇区筛选。它不支持时间窗、路线时长等额外约束；只检查返回的最佳移动，不能替代在枚举候选时逐一检查约束。浮点输入按其二进制值作精确有理数运算，浮点结果可能舍入或溢出。代码文件版本和入口见 JSON 的 `code` 字段；本项目参考实现尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check_swap_star.py](check_swap_star.py) 比较 360 组小路线对的全部交换客户与插入位置，并检查手算、无改善和异常输入；另用独立穷举程序比较 100 组含有向距离及浮点数据的小实例。这些检查不是性能基准。

**出处：** Thibaut Vidal, *Hybrid Genetic Search for the CVRP: Open-Source Implementation and SWAP\* Neighborhood*，2022；[作者稿 arXiv:2012.10384v2](https://arxiv.org/html/2012.10384v2)，第 3 节、定理 1、算法 2；[正式发表 DOI](https://doi.org/10.1016/j.cor.2021.105643)。2026-11-07 核对正文，2026-11-09 复核作者稿 HTML 第 3 节；未运行论文作者源码。
