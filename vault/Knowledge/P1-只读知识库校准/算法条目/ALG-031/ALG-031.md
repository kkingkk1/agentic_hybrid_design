# ALG-031：Kruskal 最小生成树

算法正文和摘要见 [ALG-031.json](ALG-031.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [kruskal.py](kruskal.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `kruskal`。输入顶点数及无向加权边，输出最小树总权重和树边；不连通时返回 None。允许负权和平行边；返回的是生成树，不是 TSP 回路。空图按零权空边处理。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：80 组小无向图与全部生成树候选比较，包含负边与不连通。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Dana Moshkovitz、Bruce Tidor、Ben Zinberg，*Design and Analysis of Algorithms: Complete Lecture Notes*（MIT，2012）：[来源原文](https://ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms-spring-2012/b1e5ac3c8f7d60db9b8d5b66c40bc55e_MIT6_046JS12_Notes.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：MIT 6.046 讲义 3.3 节的最小生成树和 Kruskal 算法。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
