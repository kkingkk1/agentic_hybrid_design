# ALG-019：AC-3 二元弧一致性

算法正文和摘要见 [ALG-019.json](ALG-019.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [ac3.py](ac3.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `ac3`。输入变量到有限域的映射及二元允许值对约束，输出过滤后的新域；发现空域返回 None。只支持有限二元约束，多个同对变量约束取交集；弧一致不保证整个 CSP 有解。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：100 组小约束网络与全部赋值比较，核查不会删除可行解并检查输出的弧一致性；另验证链式传播、空域和局部一致但全局无解的三变量反例。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Alan K. Mackworth，*Consistency in Networks of Relations*（Artificial Intelligence，1977）：[来源原文](https://www.cs.ubc.ca/~mack/Publications/AI77.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：Mackworth 1977 原文的 REVISE 与 AC-3 队列算法。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
