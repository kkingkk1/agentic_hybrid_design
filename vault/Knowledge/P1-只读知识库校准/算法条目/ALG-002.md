# ALG-002：CVRP 跨路线 SWAP*

**摘要：** 从两条不同路线各移出一个客户，再将两者插入对方路线的适当位置，不要求交换原位置。

**类别：** 启发式与元启发式（局部搜索算子）；**功能：** 局部改进。

**职责与接口：** 输入完整路线方案、客户需求、距离和路线容量信息；输出一个改善后的完整方案，或报告未找到可接受的移动。使用软容量时，移动评分还须接收当前罚系数，且输出不一定满足硬容量。

**机制：** 对不同路线的客户对，比较交换前后的代价，并在各自目标路线寻找插入位置。源文定理表明，最佳插入位置可从被移出客户的原位置及预先计算的前三个最佳插入位置中选取；找到改善移动后更新两条路线。

**适用条件与限制：** 源文面向 CVRP，且交换发生在不同路线。容量变化及其他约束需要一并验算；允许超容量的搜索结果须经修复或独立可行性检查。原文用仓库极角扇区相交来筛选路线对，该筛选需要位置数据，也会限制实际探索的移动集合；不能把筛选后未发现改善理解为完整邻域最优。

**开销：** 原文直接枚举的讨论为 $\Theta(n^3)$；算法 2 利用候选插入位置将完整邻域的相关计算降至 $O(n^2)$。实际重复调用的代价仍取决于路线更新和搜索策略。

**与案例的关系：** [CASE-001](../组合案例/CASE-001.md) 将此算子嵌入后代的局部搜索。本条侧重单次跨路线交换，案例侧重其与交叉、解码和种群管理的耦合。

**出处：** Thibaut Vidal, 《Hybrid Genetic Search for the CVRP: Open-Source Implementation and SWAP* Neighborhood》，2022；[作者稿 arXiv:2012.10384v2](https://arxiv.org/html/2012.10384v2)，第 3 节、定理 1、算法 2；[正式发表 DOI](https://doi.org/10.1016/j.cor.2021.105643)。2026-11-07 核对正文；未复制或运行源码。
