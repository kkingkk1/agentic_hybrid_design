# ALG-013：有向无环图最短路径动态规划

算法正文和摘要见 [ALG-013.json](ALG-013.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [dag_paths.py](dag_paths.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `dag_shortest_paths`。输入顶点数、有向边和起点，输出距离及前驱；不可达顶点为 None，边权可为负。整张输入图必须无环，即使环不可从起点到达也会报错；不求解有资源约束的路径。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：140 组小 DAG 与路径枚举比较，并检查负边、不可达及环。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Srini Devadas，*Introduction to Algorithms, Lecture 16: Dijkstra*（MIT，2011 年课程讲义）：[来源原文](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/6277a1f06100c26a7ff21031af6757b5_MIT6_006F11_lec16.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：MIT 6.006 讲义的 DAG 拓扑排序与逐边松弛。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
