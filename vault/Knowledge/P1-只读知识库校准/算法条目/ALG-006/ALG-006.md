# ALG-006：排列的顺序交叉 OX

算法正文和摘要见 [ALG-006.json](ALG-006.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [order_crossover.py](order_crossover.py) 是本项目独立实现的排列重组组件，使用 Python 3.13 标准库。`order_crossover(parent1, parent2, start, end)` 返回一个子代，不修改父代；切点是包含两端的循环区间。它不执行 Split 或其他可行性检查。

例如，父代分别为 `[1, 2, 3, 4, 5, 6, 7, 8]` 和 `[4, 5, 2, 1, 8, 7, 6, 3]`，切点为 `2, 4` 时，子代为 `[1, 8, 3, 4, 5, 7, 6, 2]`。

**与案例的差异：** [CASE-001](../../组合案例/CASE-001/CASE-001.md) 中 HGS-CVRP v1.0.0 的 `Genetic::crossoverOX` 随机选择两个不同切点。当终点恰为起点的循环前驱时，作者代码的循环不复制第一父代片段，子代排列等于第二父代；本实现将该区间视为完整循环，保留第一父代。本实现还允许相同切点作为单元素片段。两者均需后续路线解码，不能视为同一份代码。

**验证范围：** 2026-11-12 使用 [check_order_crossover.py](check_order_crossover.py) 核对手算示例、跨末尾片段、异常输入和 300 个随机排列；另以作者源码逻辑的独立重建逐切点比较，19,290 个非完整循环情况一致。5,038 个完整循环切点组合分别遵循上述保留父代规则；父代不同时输出不同。未运行作者的完整 HGS 算法，也未进行性能基准。本项目参考代码尚未单独声明开源许可；案例作者源码另按其 MIT 许可处理。

**出处：** Thibaut Vidal, *Hybrid Genetic Search for the CVRP: Open-Source Implementation and SWAP\* Neighborhood*，[作者稿 MinerU 解析](../../../../../data/P1_calibration_papers/HGS_MinerU/full.md)第 2.1 节与图 2；[作者代码 v1.0.0 固定提交](https://github.com/vidalt/HGS-CVRP/blob/35b32d8e9552074f52444d51ea1fe8aec9055467/Program/Genetic.cpp)。2026-11-12 核对解析正文和本地 CASE-001 所收录的源码。该文引用 Oliver 等 1987 年工作作为 OX 来源，本次未读取该早期文献。
