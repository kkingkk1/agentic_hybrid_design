# ALG-023：整数求和等式支持过滤

算法正文和摘要见 [ALG-023.json](ALG-023.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [sum_gac.py](sum_gac.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `sum_equals_gac`。输入有限整数域及整数目标，输出每个域的支持值；无完整支持赋值时返回 None。只处理一个等式且要求整数域，可包含负数和不连续域；不传播其他约束。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：200 组离散整数域与全部赋值比较，包括空域、负数和孔洞。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Marco Chiarandini，*Filtering Algorithms for Global Constraints*（南丹麦大学，2014 年课程讲义）：[来源原文](https://www.imada.sdu.dk/u/marco/DM826/Slides/dm826-lec9.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：讲义的广义弧一致性支持定义；本项目以可达和动态规划独立实现该特例。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
