# ALG-030：Bellman–Ford 含负边最短路径

算法正文和摘要见 [ALG-030.json](ALG-030.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [bellman_ford.py](bellman_ford.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `bellman_ford`。输入顶点数、有限边权及起点，输出距离和前驱；发现起点可达负环则报错。只报告起点可达负环；不可达负环不影响结果。检测到负环时不返回受影响顶点的逐点负无穷标签。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：100 组含负边的 DAG 与路径枚举比较，另区分可达和不可达负环。另与 SciPy 1.17.1 的 Floyd–Warshall 比较 120 个非负权图；负边情况仍由本条的 DAG 穷举检查覆盖。该库仅用于验证。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Erik Demaine、Jason Ku、Justin Solomon，*Introduction to Algorithms, Lecture 12: Bellman–Ford*（MIT，2020 年课程讲义）：[来源原文](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/2430d7903a5529451d80c17f89a41fe8_MIT6_006S20_lec12.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：MIT 6.006 Bellman–Ford 讲义的负边、松弛和可达负环。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
