# ALG-014：TSP 深度优先分支定界

算法正文和摘要见 [ALG-014.json](ALG-014.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [tsp_branch_bound.py](tsp_branch_bound.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `tsp_branch_bound`。输入非负有限距离方阵和起点，输出最短回路的精确代价与顶点序列。只支持完全图、非负距离和单个回路，不处理容量、时间窗或缺边；最坏情况仍须大量枚举。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：72 组有向小 TSP 与全部排列比较，并核查单点和负边拒绝。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Jon Bentley，*Tuning a TSP Algorithm*（MIT，2018 年课程讲义）：[来源原文](https://ocw.mit.edu/courses/6-172-performance-engineering-of-software-systems-fall-2018/dd989b76928a0561851e73da6d028763_MIT6_172F18_lec21.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：MIT 讲义的 TSP 穷举与分支定界；本条出边下界不是讲义中的 MST 下界。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
