# ALG-018：分层束搜索

算法正文和摘要见 [ALG-018.json](ALG-018.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [beam_search.py](beam_search.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `beam_search`。输入无权图、起终点、束宽、深度上限和启发函数；返回路径或 None。可能因宽度限制或深度上限而漏解，不保证最优；None 不证明无解。相同启发值按生成顺序处理。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：构造反例验证窄束会漏解、较宽束找到解，并核查深度与参数。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Yuan Shen，*Tutorial 1: Rule-based Systems, Search*（MIT，2010 年课程材料）：[来源原文](https://ocw.mit.edu/courses/6-034-artificial-intelligence-fall-2010/f0d6c16f941891b8a270b9b6f5358b98_MIT6_034F10_tutor01.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：MIT 6.034 讲义的 Beam Search、束宽和不完备性。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
