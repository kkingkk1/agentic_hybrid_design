# ALG-033：Hopcroft–Karp 二分图最大匹配

算法正文和摘要见 [ALG-033.json](ALG-033.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [hopcroft_karp.py](hopcroft_karp.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `hopcroft_karp`。输入左右顶点数和二分边，输出互不共享端点的匹配对。只优化匹配数量，不处理边权或额外容量；递归深度受 Python 栈限制。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：100 组小二分图与所有分配枚举比较，检查边与端点唯一。另与 SciPy 1.17.1 的二分匹配实现比较 100 个图；该库仅用于验证，不是参考实现依赖。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** John E. Hopcroft、Richard M. Karp，*An $n^{5/2}$ Algorithm for Maximum Matchings in Bipartite Graphs*（1973）：[来源原文](http://cse.unl.edu/~choueiry/Documents/MaxMatching-HopdcroftKarp.pdf)；[DOI](https://doi.org/10.1137/0202019)。2026-11-12 通过 Exa 阅读相关正文节选：Hopcroft–Karp 1973 原文的最短增广路径分阶段匹配。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
