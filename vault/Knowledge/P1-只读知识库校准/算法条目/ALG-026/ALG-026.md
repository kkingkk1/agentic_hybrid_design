# ALG-026：原点可行的原始单纯形法

算法正文和摘要见 [ALG-026.json](ALG-026.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [primal_simplex.py](primal_simplex.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `primal_simplex`。输入矩阵 A、非负右端 b 和目标 c，求解最大化 $c^\top x$，满足 $Ax\le b$ 和 $x\ge 0$；返回最优或无界状态。要求 b 非负，仅支持小于等于约束和非负变量；不实现两阶段法、整数约束或一般模型转换。数值结果使用 Python `Fraction`；浮点输入按其二进制值转换。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：100 个二维有界 LP 与顶点枚举比较，另检查无界和非法初始基。另与 SciPy 1.17.1 的 HiGHS 求解器比较 200 个有界线性规划；该库仅用于验证，不是参考实现依赖。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Stanford MS&E 310 课程材料 *The Simplex Method*（作者和年份未核实）：[来源原文](https://web.stanford.edu/class/msande310/lecture09.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：Stanford 单纯形讲义的可行基、最小比率、无界和 Bland 规则。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
