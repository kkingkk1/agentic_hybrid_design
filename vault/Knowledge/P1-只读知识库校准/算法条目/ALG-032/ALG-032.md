# ALG-032：Edmonds–Karp 最大流

算法正文和摘要见 [ALG-032.json](ALG-032.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [edmonds_karp.py](edmonds_karp.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `edmonds_karp`。输入顶点数、有向边容量及不同源汇，输出最大流值和残量网络的源点可达集合。容量须为非负整数；平行边合并。本实现不输出逐边流量，也不处理费用或多商品流。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：100 组小网络与全部源汇割比较，并核对返回割的容量。另与 SciPy 1.17.1 的最大流实现比较 100 个网络；该库仅用于验证，不是参考实现依赖。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Jack Edmonds、Richard M. Karp，*Theoretical Improvements in Algorithmic Efficiency for Network Flow Problems*（1972）：[来源原文](https://raw.githubusercontent.com/deltadbu/UCAS_algorithm_course/master/Lectures/EdmondsKarp1972.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：Edmonds–Karp 1972 原文中每次采用最少弧数增广路径的规则。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
