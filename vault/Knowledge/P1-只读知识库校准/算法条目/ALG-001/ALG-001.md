# ALG-001：CVRP 巨型路径的线性 Split

算法正文和摘要见 [ALG-001.json](ALG-001.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [split.py](split.py) 是本项目按 Split 论文中的硬容量、车辆数不限基本情形独立实现的参考组件，不是论文作者源码，也不是 CASE-001 中的 HGS 源码。使用 Python 3.13 标准库；`split_hard_capacity` 按既定客户顺序接收需求、容量、仓库往返距离及相邻客户距离，返回最小距离和零起始、左闭右开的路线位置区间；无可行划分返回 `None`。空输入返回零代价和空路线；长度不符、负值或非有限输入报错。浮点输入按其二进制值作精确有理数运算；含浮点距离时，输出距离转回浮点数，可能舍入或溢出。按给定十进制精度判定时，需求和容量须按相同倍率缩放为整数，距离可另行缩放。

例如，加载该文件后调用 `split_hard_capacity([3, 2, 4], 5, [1, 2, 3], [1, 2, 3], [1, 1])`，返回 `(10, [(0, 2), (2, 3)])`：前两个客户在一条路线，第三个客户在另一条路线，总距离为 10。

该代码不实现车辆数上限、软容量罚项、路线时长或时间窗。队列操作次数为线性；精确有理数运算的单位成本随数值位数变化。CASE-001 的 HGS Split 使用软容量罚项及有限车辆处理；不能仅凭方法名称把两种实现视为相同或直接替换。代码文件版本及入口见 JSON 的 `code` 字段。本项目参考实现尚未单独声明开源许可；案例中的 HGS 代码仍使用其原有 MIT 许可。

**验证范围：** 2026-11-12 使用 [check_split.py](check_split.py) 核对手算实例、无解、零需求、异常输入及 480 个小实例的全部连续分段；另以独立的前驱枚举动态规划核对 300 个整数与浮点混合输入的小实例。上述检查不能证明所有输入均正确，也不是性能基准。

**出处：** Thibaut Vidal, *Technical Note: Split Algorithm in O(n) for the Capacitated Vehicle Routing Problem*；[作者稿 arXiv:1508.02759v3](https://arxiv.org/html/1508.02759v3)，第 1、3—4 节、算法 2—3；[正式发表 DOI](https://doi.org/10.1016/j.cor.2015.11.012)。2026-11-07 核对作者稿正文，2026-11-09 复核上述章节的 HTML；未运行论文作者源码。作者稿算法 2 第 4 行与后文对 $f$ 的定义存在记号疑点，实际编码前须结合原文和实现核对，不能直接照抄。
