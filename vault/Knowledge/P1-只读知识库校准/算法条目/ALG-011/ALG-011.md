# ALG-011：0/1 背包容量动态规划

算法正文和摘要见 [ALG-011.json](ALG-011.json)。JSON、代码和本页的来源记录共同对应一个条目。

**参考代码：** [knapsack_dp.py](knapsack_dp.py) 是本项目独立编写的 Python 3.13 标准库参考实现；入口为 `knapsack_dp`。输入非负整数重量、价值和容量，输出最大价值与原物品下标；允许零重量。只处理单容量 0/1 背包；容量数值大时表会很大，不处理多维约束。本项目参考代码尚未单独声明开源许可。

**验证范围：** 2026-11-12 使用 [check.py](check.py) 完成以下检查：180 组小背包与全部子集比较，包含零重量。这些小规模检查不构成性能基准或全输入正确性证明。

**出处与核查：** Erik Demaine，*Introduction to Algorithms, Lecture 21: Knapsack*（MIT，2011 年课程讲义）：[来源原文](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/3484e876d81aba07911a1109f5b5e81e_MIT6_006F11_lec21.pdf)。2026-11-12 通过 Exa 阅读相关正文节选：MIT 6.006 讲义的 Knapsack 状态、递推和伪多项式复杂度。未逐页阅读完整来源。代码由本项目独立实现，其接口、适配、限制和实际开销以上述 JSON 与代码为准。
